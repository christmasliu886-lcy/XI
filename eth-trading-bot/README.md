# ETH 合约自动交易系统 v1.0

## 系统架构

```
eth-trading-bot/
├── main.js          # 主程序
├── src/
│   ├── config.js    # 配置文件
│   ├── data.js      # 数据获取
│   ├── indicators.js # 技术指标
│   ├── signals.js   # 信号生成
│   ├── trading.js   # 交易执行
│   ├── stats.js     # 统计分析
│   └── notifier.js  # 通知模块
└── data/
    └── trades.json  # 交易记录
```

## 功能特性

### 交易逻辑
- **品种**: ETH/USDT 合约
- **杠杆**: 10x 固定
- **止损**: 以损定仓，单次亏损 ≤ 2%
- **止盈**: 分批止盈 (5% → 10% → 20% → 移动止盈)

### 入场条件
- 顺大势 (1H/4H/日线趋势)
- 逆小势 (15分钟回调/反弹)
- 量价背离 (成交量 < 50% 7日均量)

### 风控规则
- 单日亏损 ≥ 10% 停手

### 统计分析
- 胜率、盈亏比
- 最大浮盈/浮亏
- 连胜/连亏统计

## 运行方式

```bash
cd /root/.openclaw/workspace/eth-trading-bot
node main.js
```

## 注意事项

1. **模拟交易**: 当前版本为模拟交易，不会真实下单
2. **API Key**: 如需实盘，需要配置 Binance API Key
3. **风险**: 合约交易风险大，请谨慎使用
